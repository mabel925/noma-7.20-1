# 本次发布与手机测试说明

## 拍摄与识物

- 手机只准备一张 512px 宽、质量 0.7 的 JPEG，请求体只携带一份 Base64，Worker 同时交给 Qwen 和 PicWish。
- Qwen 只生成标题、分类和标签，预算保持 5 秒；不再为 Chat 生成颜色、材质、特征和品牌。
- 快门使用本地登录和额度快照，不独立发起额度校验请求、不预扣前端额度。
- `process-image` 内部原子记账一次，超额时不调用付费供应商；响应头同步真实剩余额度。
- 识物失败继续使用 `Scanned Item`，抠图失败使用照片缩略图。
- 移除 Gemini 识物兜底及 Chat 图片生成路径。

## 登录

- 验证码成功后完成账户初始化和套餐额度读取，再关闭登录弹窗并继续待执行动作。
- 登录状态监听和验证码回调复用进行中的账户加载请求。
- 新登录会调用 Supabase `signOut({ scope: "others" })` 撤销其他会话。旧设备未过期的访问令牌仍可能短暂有效；这不是逐请求立即踢出的实现。
- 本地开发环境支持任意邮箱和验证码 `000000`，生产构建关闭此功能。

## Chat 与 Memory

- 依据真实物品、标签和地点检索，显示物品贴纸和可横滑的父级/子级地点卡片，点击直接进入详情。
- 移除输入框上方标签，调整卡片间距和横向滚动范围，保留角色站立区域。
- 修复子级地点头图、编辑标题位移和重拍按钮位置；调整头图渐变装饰、圆角、分段入场和标签选中线动画。
- 保留已有属性字段读取兼容性，但此次拍摄不新增后台 AI 属性补全任务。

## 数据维护

- R2 图片引用数为零满 3 天后才进入定时清理；仍被地点记录引用的图片保留。
- 用户统计视图只显示已验证邮箱；定时清理创建超过 24 小时且从未验证、从未登录的账号。
- Worker 每天北京时间 03:00 执行维护，两项任务相互独立。

## 部署和数据库

GitHub 推送只同步源代码，前端须等待 Cloudflare Pages 构建部署完成。Worker 已部署短识物结果格式；本次前端复用其兼容接口。

Supabase SQL 不会随 GitHub 推送自动执行。若此前尚未执行，请在 SQL Editor 分别运行：

| 迁移 | 用途 |
| --- | --- |
| `supabase/migrate_chat_search_v6.sql` | 保存与检索物品标签及兼容属性 |
| `supabase/migrate_media_gc_v1.sql` | 图片清理领取与地点图片保护 |
| `supabase/migrate_auth_hygiene_v7.sql` | 正式用户统计、未验证账号清理候选 |
| `supabase/migrate_ai_scan_authorization_v8.sql` | 从扫描授权中移除账户初始化和白名单检查 |

此次新准备的 `v8` 迁移尚未确认在线执行。它保留一次服务端原子记账网络往返，不能保证 `auth_ms` 降至 200ms。

## 手机测试

1. 等待 Pages 部署成功，重新打开 PWA 并完成本次版本更新。
2. 拍摄相同物品，分别观察快门响应、等待结果时间、标题和抠图是否成功。
3. 连续测试几次，再静置后测试首次拍摄；比较完整流程，不只看 Qwen 的 5 秒预算。
4. 本次不更换数据库区域，不调整 Worker 区域，也不延长 Qwen 等待预算。

自动验证覆盖 Worker 行为与结果契约，另有 TypeScript 检查和生产构建；未代替手机端性能实测或在线数据库迁移验证。
