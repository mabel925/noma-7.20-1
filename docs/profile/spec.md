# Profile

## L1 定位
头像入口打开完整个人资料页；本人可查看账户、套餐、物品数，编辑用户名、切换英文/简体中文、退出登录。语言为本机设置，默认英文，不改已保存的用户物品、地点或历史输入。新拍摄的物品由同一次识物请求直接生成当前语言的标题，中文使用已有的字魂扁桃体，英文使用Alkatra。

## L2 骨架 B
共用顶部返回导航；居中头像/用户名/邮箱；套餐摘要；语言入口；底部退出操作与安全说明。按用户附图实现，不发散替代布局。桌面沿用 393×852 预览框，手机全屏并避让安全区。

## L3 链路
头像→Profile→返回原页面。语言入口→同页语言列表→选择即生效并返回 Profile。用户名右侧复用编辑 icon→原位下划线输入；键盘确认保存，收起键盘/失焦/Escape取消未确认的修改，不显示Save/Cancel按钮。中文输入法选词的Enter不提交。退出成功关闭页面；失败保留页面提示重试。

## L4 组件
PageNavigation 共用导航；EditPencilIcon 复用编辑；SafeIcon 使用用户 SVG，16×16。套餐由已缓存 aiAccess 提供，不发新增查询。本人邮箱完整展示，长用户名省略；编辑态可见完整值。

## L5 状态
加载用稳定摘要占位；额度读取失败显示暂不可用，不伪装为 0 或不限量。编辑错误保留输入，保存中禁用重复提交；未登录保留原邮箱验证码流程。语言保存失败时本次仍生效；切出看验证码的恢复逻辑保留。关闭 Profile 不销毁首页/聊天/Memory 状态。

## L6 验收
- 头像打开页面而非旧弹窗；返回保持来源页面。
- 英中切换即时生效，刷新后保留；账户数据不变。
- 拍摄开始时固定识物语言；中文生成简短简体中文名称，英文生成英文名称，旧客户端未传语言时默认英文；分类字段保持原白名单，识别失败继续使用Scanned Item兜底，不新增翻译请求。
- 用户名编辑保存/取消可用，长名称与邮箱不撑破布局。
- 套餐加载/错误、退出失败均可恢复；本地任意邮箱+000000仍可测试。
- 复用返回、编辑 icon，并按附图安置底部 safe icon。
