# Profile 视觉与交互

附图是唯一布局参考：浅米底色、黑色共用导航、80px圆头像及白色描边、20px粗用户名、12px灰邮箱、白色大圆角分组，底部细描边退出按钮与灰安全说明。按附图 780px 对应 390CSS px比例。手机页面滚动时导航保持布局一致，短屏可滚动而不遮挡退出与底部说明。

Profile 使用独立 `--profile-*` token，引用原站 `--font-sans`、`--install-*`色彩和全局导航安全区。新尺寸 token 记于 gaps.log。页面淡入220ms；语言详情同页切换，遵循减少动态设置。其余拍摄/登录动效不改。

领域：auth user、aiAccess 与本机 language。摘要只读；用户名走已有 updateDisplayName；退出走已有 signOut。语言仅影响 UI 文案，用户内容与搜索数据不翻译。安全文案仅说明当前 private cloud 存储事实。

底部安全说明使用居中行内排版，安全图标紧接文字、间距为0，中英文均按实际行内容居中，换行时不保留左侧图标列。

检查：返回、键盘、超长内容、语言保持、加载/错误、权限、退出、Safari/PWA safe-area和桌面框均需验证。语言首批覆盖 Profile、登录、首页、Chat、Memory 和拍摄主界面，不调用翻译 API。
