# Desktop product introduction

- 普通电脑浏览器打开同一网址时显示左演示、右扫码的产品介绍。手机浏览器、横屏手机、iPad桌面UA和已安装PWA继续使用原应用。依据设备能力判断，不以窗口宽度强制跳转；缩小电脑窗口时介绍页折成单列。开发环境可用`?appPreview=1`或既有`?mockAuth=1`保留手机应用预览。
- 页面主任务为扫码进入`https://noma-b85.pages.dev/`，二维码静态生成，含4个模块的留白，无第三方二维码服务，无鉴权或追踪参数；网址可选择、复制，剪贴板失败可手动复制。
- 左侧是15秒循环流程演示：拍摄0–2.4s、识物2.4–5.6s、抠图5.6–7.8s、保存7.8–10.8s、寻物10.8–15s。复用现有咖啡杯和字体素材及波浪扫描渲染器，属于流程示意，不是假装在现场调用模型或承诺识别耗时。没有视频/AI接口费用。支持暂停、重播，切到后台或离开视口暂停；减少动态偏好默认静态保存结果。
- 桌面不挂载AuthProvider、相机或Memory，不走PWA启动协调器；移动端原启动检查、资源预载和登录流程保持原路径。
- Vite构建时把React介绍页预渲染到HTML；浏览器hydrate后增加语言选择和演示控制，搜索引擎无需执行JS即可读取标题、介绍、功能和网址。描述与canonical指向正式域名；不保证收录或排名。
- 桌面样式作用于独立desktop-entry容器；状态包含静态默认演示、播放/暂停、隐藏窗口、减少动态、二维码、复制成功/失败。主要视觉为米色底、品牌渐变、手机框及白色扫码卡，使用现有字体与图标风格。
- 本次同时保留上一轮未发布的浏览器圆角图标。
